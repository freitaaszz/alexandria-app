# design/

Arquivos de criação da cena 3D.

| Pasta / arquivo                 | O que é                                                                          | Vai para o GitHub?           |
| ------------------------------- | -------------------------------------------------------------------------------- | ---------------------------- |
| `blender/escola-de-magia.blend` | Cena do Blender: estante, sala, luzes e câmera                                   | Não (grande; fica no PC)     |
| `texturas/`                     | Texturas da Poly Haven (CC0) usadas no Blender                                   | Não (baixáveis de novo)      |
| `modelos/`                      | Modelos da Poly Haven (CC0): baú, sofá, quadros, plantas, lanterna               | Não (baixáveis com o script) |
| `baixar_polyhaven.py`           | Baixa os modelos: `python design/baixar_polyhaven.py treasure_chest sofa_03 ...` | Sim                          |
| `renders/`                      | Imagens de referência da cena                                                    | Sim                          |

Tudo que vem da Poly Haven é CC0 (domínio público): https://polyhaven.com
As pinturas são obras de domínio público do Art Institute of Chicago (CC0): https://www.artic.edu/open-access
